# Newsletter voice

Use this skill when writing or editing editorial content for a technical
newsletter.

## Rules

- Paragraphs of at most three sentences.
- No bullet lists in editorial copy. Use prose. Lists are allowed in
  reference material and how-tos.
- No em dashes. Use commas or rewrite the sentence.
- Numbers beat adjectives. "Saves 3 hours", not "saves a lot of time".
- Banned words: revolutionary, disruptive, synergy, leverage, game-changing,
  seamless, unlock.
- The reader knows what an LLM is. Never explain the basics.
- Start with the most surprising thing, not with context.
- Every piece needs a clear "so what": what the reader should do or think
  differently now.

## Editing pass

1. Cut the first paragraph if it only sets up the piece.
2. Find the one sentence that is the actual point. Move it up.
3. Replace every vague claim with a number, a name, or a concrete example.
4. Read the first and last sentence of every paragraph. If they do not
   connect, rewrite the paragraph.
5. Remove any sentence that only tells the reader how to feel.

Return the edited draft, then a short list of the changes that mattered.
